# Access notes - Chowdiah Memorial Hall

## Step-free route

Gate 2 on 16th Cross -> forecourt path -> Gate 2 ramp -> stalls foyer -> Main Auditorium (ground floor, two wheelchair spaces in row K).

Step-free entry is only via Gate 2 on 16th Cross, which is kept shut. Ring the call bell; an usher opens it from 45 minutes before each concert.

## Main entrance (front steps)

Eleven granite steps up to the violin-shaped facade; no ramp at the front.

## Gate 2 ramp

Gate 2 ramp is about 9 m at roughly 1:12, handrails both sides, level landing at the top.

## Accessible toilet

Accessible toilet off the stalls foyer, left-hand transfer, grab rails both sides.

## Hearing loop

No induction loop installed; no assistive listening offered.

## Accessible parking

No reserved accessible bays; drop-off at Gate 2 is possible, street parking on 16th Cross.

## Gate 2 (16th Cross)

Gate 2 is kept shut; ring the call bell and an usher opens it from 45 minutes before each concert.

## Gate 2 call bell

Call bell at Gate 2 tested; it rings at the box office.

## Forecourt path

Forecourt path from Gate 2 resurfaced, about 1.6 m clear.
